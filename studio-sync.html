Studio Archive Gateway

Studio Archive Gateway is the public information page for Project Ivy 33's internal Studio Sync authorization and archive-index workflow. It is intended for authorized studio administration, not general public sign-up.

What the integration does

The integration uses Google authorization to update and verify a studio-controlled Google Docs reference index of approved internal directives. Access is used for that archival purpose only. This index is not a comprehensive backup of all studio assets or source code.

Who operates it

Operated by Project Ivy 33. General inquiries: contact@projectivy33.com. Privacy inquiries: privacy@projectivy33.com.

Privacy and authorization

Read our Privacy Policy to understand authorization, data handling, and how to revoke access. No OAuth tokens, private archives, or confidential studio materials are published on this site.
